Installer en 4 étapes

  1. Touchez Télécharger pour Android, puis téléchargez le fichier .apk de la dernière version.
  2. Ouvrez le fichier téléchargé. Si Android le demande, autorisez l'installation depuis votre navigateur (« Sources inconnues »).
  3. Touchez Installer, puis Ouvrir.
  4. Suivez le petit guide de 3 écrans. C'est prêt.

Pour une mise à jour, installez simplement la nouvelle version par-dessus : vos données sont conservées.

Tutoriels

1. Ajouter une échéance
  1. Touchez le bouton Ajouter.
  2. Écrivez une phrase dans la case du haut, par exemple « Loyer 150 USD le 5 », ou remplissez le formulaire : titre, montant, devise, date.
  3. Choisissez les rappels (3 jours avant, le jour même…), puis Enregistrer.
2. Coller un SMS Mobile Money
  1. Copiez le SMS de confirmation (M-Pesa, Airtel Money, Orange Money…).
  2. Touchez Ajouter, collez le SMS dans la case du haut.
  3. Montant, date et référence sont remplis, et l'opération est déjà marquée payée. Vérifiez, puis enregistrez.
3. Recevoir les rappels
  1. Au premier lancement, acceptez les notifications.
  2. Si les rappels n'arrivent pas : Réglages Android → Applications → ÉCHÉANCE → Notifications, et autorisez-les. Sur certains téléphones, désactivez aussi l'optimisation de batterie pour ÉCHÉANCE.
4. Créer un compte et utiliser 2 téléphones
  1. Dans l'app : Réglages → Mon compte → créer un compte avec votre e-mail.
  2. Confirmez l'e-mail reçu, puis choisissez un mot de passe de sauvegarde et notez-le bien : il protège vos données, nous ne pouvons pas le retrouver.
  3. Sur le 2e téléphone, installez l'app et connectez-vous avec le même compte. Vos échéances arrivent seules.
  4. Si la cloche vous prévient d'une connexion inconnue, touchez Ce n'est pas moi : un mail vous permet de changer le mot de passe.
5. Passer en PRO (paiement M-Pesa)
  1. Touchez le bouton ESSAI ou PRO en haut de l'accueil.
  2. Choisissez une offre : 1 mois 1,99 $, 3 mois 4,99 $ ou 1 an 17,99 $.
  3. Envoyez le montant par M-Pesa, puis saisissez la référence de la transaction dans l'app.
  4. Après vérification, votre code PRO arrive dans l'app. Il fonctionne sur 2 téléphones au maximum.

Essai gratuit de 14 jours. Ensuite, la version gratuite garde 5 échéances actives.
