Politique de remboursement

Dernière mise à jour : 6 novembre 2026

Dans quels cas vous pouvez être remboursé, et comment faire.

1. Essayez avant d'acheter

ÉCHÉANCE PRO est offert 14 jours au premier lancement, avec toutes les fonctions. Nous vous invitons à bien l'essayer avant de payer.

2. Quand êtes-vous remboursé ?

Vous pouvez demander un remboursement dans les 7 jours suivant votre paiement dans les cas suivants :

  • La licence n'a pas pu être activée malgré un paiement vérifié, et nous n'arrivons pas à corriger le problème ;
  • Un problème technique majeur vous empêche d'utiliser les fonctions PRO achetées, et il n'est pas résolu après que vous nous l'avez signalé ;
  • Double paiement ou erreur de montant : nous remboursons la somme payée en trop.

3. Quand le remboursement n'est-il pas possible ?

  • Une fois la licence activée et fonctionnelle, un simple changement d'avis n'ouvre pas droit au remboursement (c'est le rôle de l'essai gratuit) ;
  • Une licence suspendue pour abus ou partage ;
  • Un paiement envoyé à un numéro qui n'est pas celui affiché dans l'application ;
  • Une demande faite plus de 7 jours après le paiement, sauf erreur de notre part.

Cette politique ne retire aucun droit que la loi vous reconnaît.

4. Comment demander ?

Écrivez-nous sur WhatsApp ou par e-mail avec :

  • votre numéro de commande (ex. CMD-XXXX) ou le code de licence ;
  • la référence de la transaction (SMS de confirmation) ;
  • une courte explication du problème.

Nous répondons en général sous 72 heures.

5. Comment êtes-vous remboursé ?

Le remboursement est envoyé par Mobile Money, vers le numéro qui a effectué le paiement et dans la même monnaie. Les frais de l'opérateur pour l'envoi peuvent être déduits. Après remboursement, la licence concernée est désactivée ; vos données restent sur votre téléphone.
